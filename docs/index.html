PLM Tracking Sandbox

Run the acquisition and re-acquisition logic against a synthetic aerial scene in the browser, and watch the pipeline step through it frame by frame.

Run the demo

git clone https://github.com/OmerNeeman/PerceptionLM-Demo.git
cd PerceptionLM-Demo
python3 run_demo.py --mock
xdg-open output/viewer.html

Mock mode is pure standard library — no GPU, no model downloads, no installs. It simulates the pipeline's logic (grounding, propagation, re-acquisition, analysis), not model behaviour.

Source and real-mode instructions: github.com/OmerNeeman/PerceptionLM-Demo
