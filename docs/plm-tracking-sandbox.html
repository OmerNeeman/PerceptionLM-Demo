PLM Tracking Sandbox

PerceptionLM grounding → SAM 2 propagation → PLM analysis · simulated

A playable simulation of the aerial tracking pipeline from the PerceptionLM review. Describe a target in words and run the pipeline: PLM grounds the description to a box on one frame, SAM 2 propagates it as a masklet through the video (with periodic PLM re-acquisition for objects entering the scene), and a PLM analysis pass summarizes each finished track. Models are simulated so it runs entirely in your browser — the same flow runs for real in demos/plm_aerial_tracking.

In the real pipeline every simulated step maps to a model call: grounding = facebook/Perception-LM-8B on a 36-tile 448² frame ("provide the bounding box of …"); propagation = sam2.1_hiera_large video predictor seeded with that box; analysis = PLM RDCap-style prompting on a crop clip around the track. Try queries the scene can and cannot answer — matching is intentionally literal, like a grounding model's.
