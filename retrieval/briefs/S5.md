## Goal

A **local interactive app** the owner opens and plays with: type any
description, get ranked located tiles back, **one row per scale**, with a
confidence band and a resolution caveat that tells the truth.

The shareable standalone HTML is **S5b, a separate stage.** Do not build it here.

## Why local first

F-8 was amended (owner, 2026-09-08): free-text querying lives **only** on the
local side. Measured reason — RemoteCLIP's text tower is **123.7 M params,
247 MB fp16**, against a 16 MB export cap. It cannot ship in a file. Locally the
model is already loaded, so free text is free.

## What it must do

**U-1 — opens in a working state.** Example queries visible and clickable at
rest. Seed them from the four vocabularies the owner named: small objects
(`tents`, `a car`), structures (`a building with a flat roof`), terrain
(`dirt road`, `sand`, `palm trees`). Never a blank box.

**U-2 — results are a scored, located grid, grouped one row per scale**, each
row labelled with its **true ground extent** (448 -> 44.8 m, 224 -> 22.4 m,
112 -> 11.2 m on this UTM AOI; get it from `geo.py`, do not hardcode). Each hit
shows thumbnail, score in **fixed-width** formatting, date, lat/lon. **Scores
are only ever compared within a row** — this is F-4's owner decision, and the
UI must not invite cross-row comparison.

**U-3 — the confidence band, not a verdict.** Show where the query's top score
falls against the stored background set, per scale. **Never hide or reorder
results by it.** Wording is a requirement: low confidence reads **"may not be
present"**, never "is not present". Measured justification: no statistic
separates present from absent on this corpus — `a snowy mountain` (absent)
outscores `a car` (present).

**U-4 — feedback on anything over 300 ms**, specifically first query (model
warm-up, ~9 s) and any Q&A call.

**U-5 — the resolution limit is stated in the interface.** Effective optical
resolution is **~35-45 cm**, not the 10 cm grid: presence and coarse class only,
**never fine attributes**. `CLAUDE.md` calls this the most important UX
requirement in the spec, because the demo exists to inform a build/don't-build
decision and overstating what the imagery supports corrupts that decision.
Measured backing: `a white car` retrieves the same crops as `a car`, and the
colour word makes results *worse*. **Do not offer attribute search.**

**U-6 — filter state is legible.** Active AOI/date filters visible with the
result count they produced, clearable in one action.

**U-7 — responsive from 375 px.** Grid reflows; no horizontal page scroll.

**U-8 — a tile opens** to a larger view with score, scale, date, lat/lon. The
question box is **F-9/S5a, not this stage** — leave the hook, render no
placeholder.

## Acceptance criteria — test-first, paste RED then GREEN

Test the app's **logic** (query -> per-scale results -> band -> geo), not
pixel layout:

- `test_query_returns_one_ranking_per_scale` — `len(SCALES)` rows, each tagged
  with scale and true ground extent
- `test_results_carry_location` — every hit has lat/lon, date, source, offsets
- `test_confidence_band_present_not_gating` — band returned; result count is
  identical with the band ignored
- `test_examples_present_at_rest` (U-1) and `test_resolution_caveat_in_page`
  (U-5, D-5) — assert the caveat string is actually rendered
- `test_no_external_refs` — no `src`/`href` to any external origin
- `test_first_query_latency_reported` (U-4)
- All **116** existing tests stay green.

Then **use it yourself as an impatient user** before handing back: empty query,
whitespace, a 500-character query, a query in another language, rapid repeated
submits, a nonsense string, a bbox filter matching nothing. Report what
happened. Nothing may show a stack trace.

**Env vars do not persist between Bash calls — prefix every invocation inline.**

- Data directory READ-ONLY. **Do not rebuild `index/emb/` or `index/export/`.**
- **Tests must not write under the real index root** — that defect was fixed at
  S4; use `tmp_path`. Re-check `index/tileplan/*.json` still holds 108,542 across
  three scales after your suite run.
- dtype via `device.py`, paths via `config.py`, ids via `posix_key()`. N-8
  forbids machine paths in `src/`, docstrings included.
- Tile ids encode **grid indices, not pixel offsets** (`col x scale`). Get geo by
  joining the tile plan, never by parsing ids.
- `open_clip`'s "initialized randomly" warning is benign — **suppress it in the
  app's startup output.** The owner will see this console and it reads like a
  failure.
- Never commit weights, tiles, embeddings.
