## Method

1. Cut one calibration subregion from `X605_Y3388.tif` (the tent camp) that
   visibly contains tents, cars, palm trees, buildings and sand track — roughly
   2048x2048 px, chosen by eye from a thumbnail.
2. Tile it at **448, 224 and 112 px**, 0% overlap. Keep each crop as a PIL
   image plus its pixel offsets.
3. For each candidate: embed every crop, embed the query set, rank by cosine.
4. Query set: `tent`, `tents`, `a white car`, `car`, `palm trees`,
   `a building with a flat roof`, `dirt road`, `sand`. Plus one known-absent
   control: `aircraft carrier`.
5. For each candidate x query, write the **top-5 crops as PNGs** into
   `retrieval/index/calib/<model>/<query>/` and **read them back with the Read
   tool** to judge whether they are genuine hits. Judgement is visual; say what
   you see, and say when you cannot tell.

## Acceptance criteria — test-first, paste RED then GREEN

- **N-3** `test_dtype_and_cuda`: `torch.cuda.is_available()` is True and the
  loaded model dtype is `torch.float16`. The CUDA assertion is what catches the
  shadowed CPU torch; a failure here means `PYTHONNOUSERSITE` was not set, not
  that the hardware is broken.
- **F-2** `test_embed_unit_norm`: every returned image vector has
  `||v||_2 = 1.0 +/- 1e-5`; dimensionality matches the candidate's stated dim.
- **F-3** `test_text_embed_deterministic`: the same query string embeds
  identically within a process and to within 1e-6 across processes; norms are
  unit.
- **F-4-lite** `test_self_similarity`: a vector's cosine with itself is
  `1.0 +/- 1e-5`.
- **F-0**: `briefs/S0_result.md` contains a table of candidate x query with the
  top-5 verdicts, the measured tiles/sec for each candidate, and **one stated
  choice with a reason**.
